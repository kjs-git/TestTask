# TestTask API

REST API сервис для загрузки, обработки и анализа CSV файлов с показателями. Проект реализован на .NET 10 и использует PostgreSQL. 

## Запуск проекта

Для локального развертывания требуется установленный Docker и Docker Compose. 

1. Откройте терминал в корневой папке проекта (где находится файл `docker-compose.yml`).
2. Выполните команду сборки и запуска:
   ```bash
   docker-compose up -d --build
